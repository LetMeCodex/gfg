# [Longest Subarray Sum Divisible by K](https://www.geeksforg eeks.org/problems/longest-subarray-with-sum-divisible-by-k1259/1)
- **Platform**: GeeksforGeeks (Problem of the Day)
- **Difficulty**: Medium
- **Solved In**: 2 attempt(s)

## Problem Summary

Given an array `arr` of `N` integers and an integer `k`, the task is to find the length of the longest subarray whose sum is divisible by `k`. The array elements can be positive, negative, or zero.

**Example:**
`arr = [2, 7, 6, 1, 4, 5]`, `k = 3`
- Subarray `[7, 6, 1, 4]` has sum `7+6+1+4 = 18`, which is divisible by 3. Its length is 4.
- Subarray `[2, 7, 6]` has sum `2+7+6 = 15`, which is divisible by 3. Its length is 3.
The longest such subarray has length 4.

## Intuition & Approach

### 1. Initial Thoughts (Brute Force)

A naive approach would be to iterate through all possible subarrays, calculate their sum, and check if the sum is divisible by `k`.
- To find all subarrays: $O(N^2)$ pairs of (start, end) indices.
- To calculate sum for each subarray: $O(N)$ in the worst case, or $O(1)$ if using prefix sums.
This would lead to an $O(N^3)$ or $O(N^2)$ solution. Given `N` up to $10^5$, an $O(N^2)$ solution ($10^{10}$ operations) is too slow. We need a more efficient approach, ideally $O(N)$.

### 2. Key Insight: Prefix Sums and Remainders

The sum of a subarray `arr[i...j]` can be expressed using prefix sums: `prefix_sum[j] - prefix_sum[i-1]`.
We are looking for a subarray `arr[i...j]` such that `(prefix_sum[j] - prefix_sum[i-1]) % k == 0`.

This condition is equivalent to:
`prefix_sum[j] % k == prefix_sum[i-1] % k`

This is the core idea: if two prefix sums have the same remainder when divided by `k`, then the sum of the elements between their respective indices is divisible by `k`.

To find the *longest* such subarray, when we encounter a `current_sum` at index `j` with remainder `R = current_sum % k`, we need to find the *earliest* previous index `p` where `prefix_sum[p]` also had the remainder `R`. The length of this subarray would be `j - p`. By always taking the earliest `p`, we maximize `j - p`.

### 3. Algorithm Steps

1.  **Initialization:**
    *   `max_len = 0`: Stores the maximum length found so far.
    *   `current_sum = 0`: Stores the running prefix sum. Use `long long` to prevent overflow, as array elements can be large and `N` can be up to $10^5$.
    *   `first_occurrence`: A data structure (like a hash map or an array) to store the *first* index where each remainder `R` was encountered. Since `k` is up to $10^5$, an array `std::vector<int> first_occurrence(k)` is efficient. Initialize all entries with a sentinel value (e.g., -2) to indicate that the remainder has not been seen yet.

2.  **Base Case for Remainder 0:**
    *   A prefix sum of 0 (before processing any elements, conceptually at index -1) has a remainder of 0. This is crucial for handling subarrays that start from index 0 and whose sum `arr[0...i]` is divisible by `k`.
    *   Set `first_occurrence[0] = -1`.

3.  **Iterate through the array:**
    *   For each element `arr[i]` from `i = 0` to `N-1`:
        a.  Update `current_sum += arr[i]`.
        b.  Calculate the `remainder`: `remainder = (current_sum % k + k) % k`.
            *   The `(X % k + k) % k` expression ensures that the remainder is always non-negative (in the range `[0, k-1]`), even if `current_sum` is negative (e.g., in C++, `-5 % 3` is `-2`, but `(-2 + 3) % 3` is `1`, which is the desired positive remainder).
        c.  **Check `first_occurrence`:**
            *   If `first_occurrence[remainder]` is *not* the sentinel value (meaning this `remainder` has been seen before at an earlier index `p`):
                *   Calculate the length of the subarray: `current_index (i) - first_occurrence[remainder]`.
                *   Update `max_len = std::max(max_len, i - first_occurrence[remainder])`.
            *   If `first_occurrence[remainder]` *is* the sentinel value (this is the first time we've encountered this `remainder`):
                *   Store the current index: `first_occurrence[remainder] = i`.

4.  **Return `max_len`**.

## Complexity Analysis

-   **Time Complexity**: $O(N)$
    *   We iterate through the input array `arr` exactly once.
    *   Inside the loop, operations like addition, modulo, array access, and `std::max` all take constant time, $O(1)$.
    *   Therefore, the total time complexity is linear with respect to the number of elements `N` in the array.

-   **Space Complexity**: $O(K)$
    *   We use a `std::vector<int> first_occurrence` of size `k` to store the first index of each remainder.
    *   The space required is directly proportional to `k`.

## Solution Code

```cpp
#include <vector>
#include <numeric> // Not strictly needed for the final solution, but good to keep if it was part of development
#include <algorithm> // Required for std::max

class Solution {
public:
    // Renamed the function from longestSubarraySumDivisibleByK to longestSubarrayDivK
    // to match the name expected by the GeeksforGeeks driver code.
    int longestSubarrayDivK(std::vector<int>& arr, int k) {
        int n = arr.size();
        
        // Use a vector to store the first occurrence of each remainder.
        // The size of the vector is k, as remainders will be in [0, k-1].
        // Initialize with -2 to indicate that the remainder has not been seen yet.
        // -1 is reserved for the initial state of remainder 0.
        std::vector<int> first_occurrence(k, -2); 
        
        // Initialize max_len to 0.
        int max_len = 0;
        
        // current_sum can accumulate up to 10^6 * 10^6 = 10^12,
        // so it must be a long long to prevent overflow.
        long long current_sum = 0;
        
        // The remainder 0 is considered to have occurred at index -1.
        // This handles cases where a prefix sum from arr[0] to arr[i] is divisible by k.
        // In such a case, the subarray starts at index 0 and ends at index i,
        // and its length is i - (-1) = i + 1.
        first_occurrence[0] = -1;
        
        for (int i = 0; i < n; ++i) {
            current_sum += arr[i];
            
            // Calculate the remainder.
            // The expression (current_sum % k + k) % k ensures the remainder is always non-negative,
            // even if current_sum is negative. For example, -5 % 3 in C++ is -2.
            // (-2 + 3) % 3 = 1 % 3 = 1, which is the desired positive remainder.
            int remainder = (current_sum % k + k) % k;
            
            // If this remainder has been seen before:
            if (first_occurrence[remainder] != -2) {
                // Calculate the length of the subarray whose sum is divisible by k.
                // The sum from first_occurrence[remainder] + 1 to i is divisible by k.
                // Its length is i - (first_occurrence[remainder] + 1) + 1 = i - first_occurrence[remainder].
                max_len = std::max(max_len, i - first_occurrence[remainder]);
            } else {
                // If this is the first time we see this remainder, store its current index.
                first_occurrence[remainder] = i;
            }
        }
        
        return max_len;
    }
};
```
